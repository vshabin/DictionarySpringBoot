## Project Documentation

This project exposes a set of REST APIs built with Spring Boot. Comprehensive documentation is available in the `docs/` directory and via Swagger UI when the app is running.

- API Reference per controller: see `docs/api/` (start with `docs/api/README.md`)
- Data Models reference: see `docs/models.md`
- Components/Services reference: see `docs/components.md`

Swagger/OpenAPI UI (when running): `http://localhost:8080/swagger-ui/index.html`
